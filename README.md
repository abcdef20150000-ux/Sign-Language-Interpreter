# Sign Language Recognition Project

This project aims to detect and classify simple hand gestures using Computer Vision techniques.  
OpenCV is used for video processing, while MediaPipe Hands extracts 21 hand landmarks.  
The system recognizes gestures such as Hello, Stop, Yes, No, Thank You, and I Love You in real time.

---

## Features
- Real-time gesture detection using webcam.
- Extracts 21 hand landmarks using MediaPipe Hands.
- Recognizes multiple predefined gestures.
- Lightweight and easy to run.

---

## Technologies Used
- Python  
- OpenCV  
- MediaPipe  
- NumPy

## How to Run

### 1. Make sure Python and OpenCV are installed.
If OpenCV is not installed, install it using:
```bash
pip install opencv-python
```

### 2. Clone the Repository
```bash
git clone https://github.com/YourUserName/YourRepoName.git
cd YourRepoName
```

### 3. Install Dependencies
```bash
pip install opencv-python mediapipe numpy
```

### 4. Run the Application
If the code is inside a "Code" folder:
```bash
cd Code
python main.py
```

### 5. Usage
- The webcam will open automatically.  
- Show your hand clearly to the camera.  
- The system will detect the hand and display the recognized gesture.  
- Press **Q** to exit the application.
